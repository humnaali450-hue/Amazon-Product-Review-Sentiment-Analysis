# 🛒 Amazon Product Review Sentiment Analysis

## 📌 Project Overview

This project analyzes **Amazon product reviews** to determine the **overall sentiment** expressed by customers.  
The dataset contains customer feedback in text form, which is processed, cleaned, and classified into **positive, negative, or neutral** categories.  

You will explore text preprocessing, visualizations, and build **machine learning models** to automatically classify review sentiment. This mirrors how companies leverage customer feedback to improve products and services.

---

## 🎯 Objectives

* Clean and preprocess raw text data  
* Explore customer reviews through visualizations  
* Analyze sentiment patterns in feedback  
* Build ML models for sentiment classification  
* Evaluate model performance using metrics  
* Learn real-world NLP applications

---

## 🛠️ Tools & Libraries Used

* Python  
* Pandas  
* NumPy  
* Matplotlib  
* Seaborn  
* Scikit-learn  
* NLTK / SpaCy (for text preprocessing)  
* Jupyter Notebook (VS Code)
